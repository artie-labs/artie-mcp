# Support

## Hosted Artie MCP

The supported product is the hosted server at `https://mcp.artie.com/mcp`.

| Need | Where to go |
| --- | --- |
| Connect a client, OAuth, environment linking, scopes | [MCP documentation](https://www.artie.com/docs/api/mcp) |
| Account, pipeline, connector, or Dashboard questions | [Artie Dashboard](https://app.artie.com) or your Artie support channel |
| Security vulnerability | [SECURITY.md](SECURITY.md) — not public issues |
| Bug in this repository's code or protocol behavior | GitHub issue using the bug form |
| Feature request for this repository | GitHub issue using the feature form |

## What GitHub issues are for

Public issues may cover:

- Build, test, policy-contract, or protocol bugs in this repository
- Documentation errors in files in this repository
- Clarifying the hosted-service integration behavior that this source implements

Public issues are **not** for:

- Account access, billing, or environment membership
- OAuth grant recovery or API-key rotation
- Customer pipeline state, incidents, or data
- Security vulnerabilities (see [SECURITY.md](SECURITY.md))
- Requests for a supported self-hosted deployment — that is not offered

## Self-hosting

Running this server yourself is not a supported Artie product. `mcp.artie.com` is the supported endpoint.
